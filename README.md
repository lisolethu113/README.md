# Simple Interest Calculator

## Project Description

This project contains a Bash script that calculates simple interest based on user-provided values.

The calculator accepts the following inputs:

* Principal amount
* Rate of interest
* Time period

The simple interest is calculated using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

## Project Name

Simple Interest Calculator

## Features

* Accepts principal amount from the user
* Accepts rate of interest from the user
* Accepts time period from the user
* Calculates simple interest
* Displays the calculated result

## Technology Used

* Bash Shell Script
* Git
* GitHub

## Usage

Run the following command:

```bash
bash simple-interest.sh
```

Enter the principal amount, rate of interest, and time period when prompted.

## Formula

```text
Simple Interest = (P × R × T) / 100
```

Where:

* P = Principal amount
* R = Rate of interest
* T = Time period
